# 校园网访问

## 启动服务

在服务器仓库根目录执行：

```bash
cd ~/competition/NoviceSynapse
NOVICESYNAPSE_PYTHON=/data2/sxf2026/miniconda3/envs/novicesynapse/bin/python bash deploy/start_campus.sh
```

默认监听 `0.0.0.0:8000`。`0.0.0.0` 表示服务接受服务器各网卡上的连接，便于校园网用户访问；它不是一个需要在浏览器中输入的地址。

## 访问地址

服务器当前校园网地址为 `192.168.1.5`，因此校园网用户访问：

```text
http://192.168.1.5:8000/
```

健康检查地址：

```text
http://192.168.1.5:8000/health
```

## 验证

服务器本机执行：

```bash
curl http://127.0.0.1:8000/health
curl http://192.168.1.5:8000/health
ss -lntp | grep ':8000'
```

应看到健康检查返回 `200`，并看到服务监听 `0.0.0.0:8000`。

其他校园网设备直接访问上述地址即可。测试时应关闭代理，或将 `192.168.1.0/24` 设置为直连；学校 VPN 用户需要先连接学校 VPN。

## 网络放行要求

校园网访问不需要公网端口映射，但必须允许：

```text
校园网用户网段 -> 192.168.1.5:8000/TCP
```

如果服务器本机访问正常、其他校园网设备访问失败，需要服务器管理员检查主机防火墙，或请校园网/集群网络管理员放行 TCP 8000 及对应网段。

公网端口映射不是本部署方案的一部分。若以后开放公网，再单独配置网关转发到 `192.168.1.5:8000`，并补充认证和 HTTPS。
