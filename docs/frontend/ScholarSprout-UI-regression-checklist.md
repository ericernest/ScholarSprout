# ScholarSprout UI 功能复核清单

## 自动门禁

- `npm test`：六个 Vue surface 与六个 v1 功能页一一对应，关键控件和脚本仍存在，HTML 不再显示旧品牌。
- `npm run build`：Vue TypeScript 类型检查与 Vite 多页面构建通过。
- Python 前端/存储/配置测试：公开 URL 返回构建入口，原功能合同继续由对应静态页验证。

## 页面功能合同

| 页面 | 必须保留的行为 |
| --- | --- |
| 首页 | 进入新会话、资料库、配置；本地产品定位和三大能力入口 |
| 研究对话 | 日常/领域入门/论文精读模式；上下文选择；历史恢复；PDF 文件与 URL；SSE 流式输出、中断；领域任务卡；论文卡及工作台跳转 |
| 领域入门 | 创建/恢复异步任务；SSE 阶段进度；取消、失败重试；三栏与宽度记忆；学习概览、前置知识、发展路径、概念全景、学习路线、论文清单、知识图谱；论文加入资料库和转精读 |
| 论文精读 | 本地 PDF、URL、检索导入；解析轮询与重解析；PDF/重排切换；缩放、适宽/适页、下载、全屏；章节导航与阅读地图；流式问答和 8 个 Skill；文本选择提问/高亮/笔记；远端标注；Fork 创建、切换、合并；论文笔记；面板拖拽与状态恢复 |
| 研究资料库 | 会话、领域地图、精读记录、论文四视图；搜索；精读状态筛选；PDF/URL 导入；文件夹创建、重命名、移动、删除；论文移动与管理；笔记；继续会话/领域/精读 |
| 配置 | 主模型、Embedding 与数据目录；密钥显隐；保存与运行时刷新；首次配置状态与本地隐私提示 |

## 人工端到端场景

1. 启动 Gateway，依次访问 `/`、`/app`、`/library`、`/settings`、`/app/domain-onboarding`、`/app/paper-reading`，确认标题、图标、品牌和帮助入口一致。
2. 在对话页分别执行普通对话、领域入门和 PDF 精读；确认流式文本、中断、卡片与跳转。
3. 领域任务在生成中刷新页面，确认继续恢复；测试取消、失败重试和推荐论文转精读。
4. 论文精读测试 PDF/重排、章节跳转、阅读地图、选区标注、Fork、笔记和刷新恢复。
5. 资料库验证四视图、文件夹全生命周期、状态筛选、论文笔记和继续研究。
6. 在 1366×768、1920×1080 和窄屏各复核一次；开启“减少动态效果”确认无持续装饰动画。

真实模型、外部论文检索和 PDF.js CDN 仍取决于本机配置与网络，不能用构建通过替代这些运行时验证。
