# 飞书 Channel 配置与使用说明（V1版）

## 1. 功能说明

**研究对话·研见·SeeFurther**（原NoviceSynapse）新增飞书机器人入口，通过 `FeishuChannel` 接收和回复飞书消息，并复用现有 Chat Agent。

消息流程：

```text
飞书
→ FeishuChannel
→ ChannelMessage
→ Chat Handler
→ Chat Agent
→ FeishuChannel
→ 飞书回复
```

当前版本支持：
- WebSocket 长连接
- 私聊文本消息
- 文本回复

暂不支持群聊、图片、文件、消息卡片和流式回复。

## 2. 依赖

项目需要安装飞书 Python SDK：

```text
lark-oapi
```

已将其加入 pyproject.toml 中。

## 3. 飞书应用配置

在飞书开放平台创建企业自建应用，并完成：

1. 启用机器人能力；
2. 事件订阅选择“使用 **长连接** 接收事件”；
3. 添加事件 `im.message.receive_v1`；
4. 为事件`im.message.receive_v1`开通机器人消息接收和发送权限；
5. 创建版本/发布最新版本（注：每次更改后都需要创建版本，才可实现最新更改）。

## 4. 环境变量

启动前配置：

```cmd
set FEISHU_APP_ID=your_app_id
set FEISHU_APP_SECRET=your_app_secret
```
注：
1. 在powershell的指令为：
```powershell
$env:FEISHU_APP_ID="your_app_id"
$env:FEISHU_APP_SECRET="your_app_secret"
```
2. 请勿将 App Secret、API Key 等敏感信息提交到 Git。

## 5. 启动与使用

启动 Gateway：

```cmd
novicesynapse gateway --host 127.0.0.1 --port 8000
```

出现：

```text
[Lark] [INFO] connected to wss://...
```

说明飞书长连接建立成功。

之后在飞书中私聊机器人发送文本即可。

## 6. 代码改动

本功能主要包括：

- 新增 `channels/feishu.py`，实现飞书 Channel Adapter；
- 修改 `gateway/app.py`，注册并启动 `FeishuChannel`；
- 使用环境变量读取飞书 App ID / App Secret；
- 增加飞书消息发送和重复消息去重；
- Gateway 保留 `WebChannel` 作为默认入口；
- 修复 Tool Registry 初始化，改为：

```python
tool_registry = create_builtin_tool_registry(research_storage)
```

飞书和 Web UI 共用现有 Handler、Agent、Skill、Tool 和模型能力。
