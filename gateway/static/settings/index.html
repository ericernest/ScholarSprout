SETUP GUIDE

飞书开放平台配置

  1. 在飞书开放平台创建企业自建应用。
  2. 在“应用能力”中启用机器人能力。
  3. 在“事件与回调”中选择“使用长连接接收事件”，并添加事件 im.message.receive_v1。
  4. 在“权限管理”中开通“获取与发送单聊、群组消息” im:message，以及“读取用户发给机器人的单聊消息” im:message.p2p_msg:readonly。
  5. 创建版本并发布最新版本。
  6. 在“凭证与基础信息”中获取 App ID 和 App Secret，填入上方并启用飞书机器人。
