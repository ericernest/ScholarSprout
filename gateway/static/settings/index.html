  1. 1
    准备模型信息

    从模型服务商获取 API Key、Base URL 和模型名称。

  2. 2
    选择数据目录

    会话、论文记录和上传的 PDF 都会放在这里。

  3. 3
    保存并生效

    模型、Embedding 和 MinerU 配置会立即用于新请求。

API Key 不会在页面加载时回传；这里只显示是否已经配置。
