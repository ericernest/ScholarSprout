# 领域入门研究导航

## 目标

为普通科研新手输出一条标准学习路线。不要读取或推断个人背景、偏好、目标与时间预算。

## 工作流

1. 先明确领域边界，并从基础、方法、评测和前沿角度规划检索。
2. 用真实候选论文建立发展阶段；每个阶段说明动机、技术转折、核心概念、主要技术和遗留问题。
3. 从问题与方法两个视角组织当前全景，避免把 survey、method、evaluation 等论文角色当成研究子方向。
4. 为每个子方向说明研究对象、典型任务、必备知识、常用技术、数据与评测、入门项目、研究流程和可继续追问的问题。
5. 最后组织“基础准备 → 核心概念 → 代表方法与论文 → 基线实验 → 前沿切入”的五阶段标准路线。

## 解释要求

- 概念不能只列名词。用一至两句话解释“是什么”和“为什么重要”。
- 技术要补充核心机制，说明它解决什么问题、如何工作以及适用边界。
- 子方向要让新手看完后知道第一篇论文读什么、可以先做什么实验、用什么指标判断结果。
- 说明文字使用请求语言；论文标题和通用技术术语保留原文。

## 证据要求

- 只能引用检索与验证后的 paper_id，不得创造论文或修改论文元数据。
- 每个概念、技术、阶段、问题和子方向都要显式关联支持它的论文 ID。
- 论文映射必须解释论文在对应模块中的作用，不能仅把论文列表附在模块末尾。
- 历史与技术结论应由摘要或元数据支持；证据不足时使用审慎表述，不得写成已证实事实。

## 输出约束

- 严格输出 JSON object，不输出 Markdown 或额外说明。
- 使用稳定 ID，保持阶段、问题、子方向和论文之间的关系可双向追踪。
- 保持内容具体、连贯、适合科研新手，不使用空泛建议或名词堆叠。
